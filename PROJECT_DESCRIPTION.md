# Destiny Engine - AI-Powered Vedic Astrology Platform

## Project Overview

**Destiny Engine** is a modern web application that transforms ancient Vedic astrology into an accessible, AI-enhanced experience. The platform generates personalized Kundali (birth charts) and provides intelligent astrological insights through cutting-edge artificial intelligence.

## What It Does (User-Friendly)

### For Everyone

- **Generate Your Personalized Birth Chart**: Simply enter your birth details and get a complete Vedic astrology chart with beautiful visualizations
- **AI-Powered Insights**: Our intelligent system reads your chart like an experienced astrologer, explaining complex astrological concepts in plain English
- **Life Timing Analysis**: Understand the best times for important decisions through planetary period calculations
- **Personalized Guidance**: Receive customized recommendations for spiritual practices, career insights, and life decisions

### For Developers

- **Modern Tech Stack**: Built with Next.js 15.3.2, TypeScript, and Python
- **Scalable Architecture**: Modular design ready for growth and integration
- **AI Integration**: RAG-powered system with vector database capabilities
